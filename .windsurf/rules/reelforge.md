# ReelForge

Follow `AGENTS.md` at the project root (Part 1: making videos, Part 2: the code). Task guides live
in `skills/`; the `get_guide` tool reads them.

Add the `reelforge` MCP server in Settings → Cascade → MCP servers → View raw config. The
dashboard's Connect AI page (`reelforge studio`, then `/connect`) shows the exact stdio and HTTP
configs.
