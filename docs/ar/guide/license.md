## المكوّنات الخارجية

يعتمد ReelForge على برمجيات وبيانات مفتوحة المصدر تُستخدم بموجب تراخيصها الخاصة (النصوص الكاملة في
[`THIRD-PARTY-NOTICES.md`](../../../THIRD-PARTY-NOTICES.md)):

| المكوّن                                     | الترخيص                                  |
| ------------------------------------------- | ---------------------------------------- |
| الخطوط المضمّنة (Cairo وInter وReadex Pro…) | SIL Open Font License 1.1                |
| Playwright                                  | Apache-2.0                               |
| zod وcommander وws                          | MIT                                      |
| yaml وzod-to-json-schema                    | ISC                                      |
| الأيقونات (Lucide)                          | ISC                                      |
| نموذج تنظيف الصوت RNNoise ‏(`sh.rnnn`)      | غير خاضع لحقوق النشر (بحسب إشعار المؤلف) |
| هذا الموقع: VitePress                       | MIT                                      |

يُثبَّت FFmpeg وChromium بشكل منفصل، ولا يُوزَّعان مع ReelForge.

أما نماذج الكلام الاختيارية وبيئة تشغيلها (أوزان Whisper وSilero VAD، وكلاهما MIT؛ وحزم بيئة التشغيل بتراخيص
Apache-2.0 وMIT، ومكتبة الصور libvips بترخيص LGPL-3.0-or-later) فينزّلها الأمر `reelforge align --setup` مرة
واحدة إلى مجلد التخزين المؤقت (cache) الخاص بالمستخدم، وليست جزءاً من ملفات ReelForge التي تنزّلها.
