# درس المطاعم والضيافة

في هذا الدرس تصنع فيديو موضوعه: طريقة تحضير طبق مميز في أربع خطوات لمطعم خيالي. ستستخدم الحزمة `food` وثيمها `bistro`، ويستغرق العمل نحو عشر
دقائق قبل التسجيل.

## 1. أنشئ الحلقة

```bash
reelforge new dish-steps --pack food --template dish-in-steps --lang ar
```

استخدم `--lang en` لنسخة إنجليزية. وتضم الحزمة أيضاً القالبين `order-to-table` و`weekly-menu`. يعرض [فهرس الحزم](../../reference/packs.md#food) كل القوالب
وحقولها.

## 2. أدخل بياناتك

افتح الحلقة بالأمر `reelforge edit dish-steps` واستبدل الأسماء والأرقام والكلمة المفتاحية الافتراضية
ببياناتك، أو ابدأ من لوحة التحكم (**+ New episode** ثم **Start from template**)، فيطلب النموذج كل حقل على حدة. التزم بحدود
الطول الظاهرة لكل حقل.

**الجمهور والنبرة.** رواد المطاعم ومحبو الطبخ وعملاء التوصيل. كن دافئاً وحيوياً وسريعاً، واللهجة المحلية مناسبة هنا.

- اعرض تحضير الطبق في أربع خطوات بمكوّن `steps` مع `icon` للحرارة أو الوقت.
- اذكر السعر وساعات العمل مرة واحدة واعرضهما كعناصر `chip`.
- استخدم صور أطباقك الخاصة من مجلد `assets/`.

## 3. راجع المحتوى

- لا ادعاءات صحية أو غذائية مثل «صحي» كوعد أو «يحرق الدهون».
- عند ذكر المكونات أضف «اسأل الموظفين عن مسببات الحساسية»، ولا تدّعِ خلو الطبق منها إلا إذا أكد العميل ذلك.
- أسماء مطاعم خيالية فقط؛ لا سلاسل ولا منصات توصيل حقيقية.

## 4. تحقق وسجّل وصدّر

```bash
reelforge validate dish-steps
reelforge align dish-steps          # after you save voice.wav in the episode folder
reelforge render dish-steps
```

يوجد مثال مكتمل في `packs/food/examples/shakshuka-ar`؛ صدّره مع الخيار `--silent` للمقارنة.
