# درس السياحة والسفر

في هذا الدرس تصنع فيديو موضوعه: برنامج ثلاثة أيام في بلدة ساحلية خيالية. ستستخدم الحزمة `tourism` وثيمها `voyage`، ويستغرق العمل نحو عشر
دقائق قبل التسجيل.

## 1. أنشئ الحلقة

```bash
reelforge new three-days --pack tourism --template itinerary-3-days --lang ar
```

استخدم `--lang en` لنسخة إنجليزية. وتضم الحزمة أيضاً القالبين `airport-to-town` و`best-time-to-visit`. يعرض [فهرس الحزم](../../reference/packs.md#tourism) كل القوالب
وحقولها.

## 2. أدخل بياناتك

افتح الحلقة بالأمر `reelforge edit three-days` واستبدل الأسماء والأرقام والكلمة المفتاحية الافتراضية
ببياناتك، أو ابدأ من لوحة التحكم (**+ New episode** ثم **Start from template**)، فيطلب النموذج كل حقل على حدة. التزم بحدود
الطول الظاهرة لكل حقل.

**الجمهور والنبرة.** المسافرون الذين يخططون لرحلة والزوار في المكان. كن جذاباً وعملياً.

- استخدم `timeline` للأيام و`chip` لكل محطة.
- قدّم نصيحة عملية واحدة لكل يوم (المواصلات أو التوقيت أو التذاكر).
- اختم بسؤال يدعو إلى التعليق، مثل المحطة التي يريدها المشاهد في الحلقة القادمة.

## 3. راجع المحتوى

- لا فنادق ولا شركات طيران ولا منظمي رحلات ولا منصات حجز حقيقية.
- الأسعار والمواعيد وقواعد التأشيرة كما تُقدَّم فقط، مع عبارة «تحقق قبل السفر».
- احترم الثقافة المحلية والأماكن المقدسة، ولا قوالب نمطية.

## 4. تحقق وسجّل وصدّر

```bash
reelforge validate three-days
reelforge align three-days          # after you save voice.wav in the episode folder
reelforge render three-days
```

يوجد مثال مكتمل في `packs/tourism/examples/azur-bay-ar`؛ صدّره مع الخيار `--silent` للمقارنة.
