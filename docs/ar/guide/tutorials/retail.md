# درس التجزئة

في هذا الدرس تصنع فيديو موضوعه: شرح خدمة الطلب عبر الإنترنت والاستلام من المتجر لمتجر خيالي. ستستخدم الحزمة `retail` وثيمها `retail`، ويستغرق العمل نحو عشر
دقائق قبل التسجيل.

## 1. أنشئ الحلقة

```bash
reelforge new click-and-collect --pack retail --template click-and-collect --lang ar
```

استخدم `--lang en` لنسخة إنجليزية. وتضم الحزمة أيضاً القالبين `returns-steps` و`loyalty-program`. يعرض [فهرس الحزم](../../reference/packs.md#retail) كل القوالب
وحقولها.

## 2. أدخل بياناتك

افتح الحلقة بالأمر `reelforge edit click-and-collect` واستبدل الأسماء والأرقام والكلمة المفتاحية الافتراضية
ببياناتك، أو ابدأ من لوحة التحكم (**+ New episode** ثم **Start from template**)، فيطلب النموذج كل حقل على حدة. التزم بحدود
الطول الظاهرة لكل حقل.

**الجمهور والنبرة.** المتسوقون وموظفو المتاجر. كن حيوياً وملموساً، وابدأ بالفائدة، واستخدم جملاً قصيرة.

- ضع الفائدة في الافتتاحية، مثل مدة تجهيز الطلب.
- اعرض الخطوات على `phone` أو بمكوّن `steps`: اطلب عبر الإنترنت، وانتظر الرسالة، ثم استلم.
- اذكر أي شروط (ساعات العمل، أو الهوية المطلوبة) وكررها في نص المنشور.

## 3. راجع المحتوى

- الأسعار والخصومات والتواريخ كما يقدمها العميل حرفياً، مع شروطها.
- لا استعجال مصطنع مثل «بقيت قطعتان فقط» إلا إذا كان صحيحاً.
- لا علامات تجارية حقيقية ولا مقارنات مع منافسين مسمّين.

## 4. تحقق وسجّل وصدّر

```bash
reelforge validate click-and-collect
reelforge align click-and-collect          # after you save voice.wav in the episode folder
reelforge render click-and-collect
```

يوجد مثال مكتمل في `packs/retail/examples/bluebell-pickup-ar`؛ صدّره مع الخيار `--silent` للمقارنة.
