# درس التصنيع

في هذا الدرس تصنع فيديو موضوعه: كيف تُصنع قطعة في مصنع خيالي، من المادة الخام حتى التغليف. ستستخدم الحزمة `manufacturing` وثيمها `industrial`، ويستغرق العمل نحو عشر
دقائق قبل التسجيل.

## 1. أنشئ الحلقة

```bash
reelforge new part-journey --pack manufacturing --template part-journey --lang ar
```

استخدم `--lang en` لنسخة إنجليزية. وتضم الحزمة أيضاً القالبين `safety-mistake` و`downtime-causes`. يعرض [فهرس الحزم](../../reference/packs.md#manufacturing) كل القوالب
وحقولها.

## 2. أدخل بياناتك

افتح الحلقة بالأمر `reelforge edit part-journey` واستبدل الأسماء والأرقام والكلمة المفتاحية الافتراضية
ببياناتك، أو ابدأ من لوحة التحكم (**+ New episode** ثم **Start from template**)، فيطلب النموذج كل حقل على حدة. التزم بحدود
الطول الظاهرة لكل حقل.

**الجمهور والنبرة.** المشغّلون والفنيون والمشترون والمتقدمون للعمل. كن دقيقاً، واجعل السلامة أولويتك.

- اعرض المراحل بمكوّن `flow` مع مؤشر متحرك (token)، مرحلة لكل خطوة منطوقة.
- ميّز فحوص الجودة بـ `node` يتحول `status` الخاص به إلى الأخضر عند نطق الكلمة.
- أبقِ المصطلحات التقنية الإنجليزية داخل الجملة العربية.

## 3. راجع المحتوى

- خطوات السلامة من الإجراءات الرسمية للعميل فقط.
- المؤشرات (نسبة الهدر، التوقف) من العميل فقط، وإلا فهي «مثال».
- لا معايير تشغيل سرية ولا أسماء شركات أو آلات حقيقية.

## 4. تحقق وسجّل وصدّر

```bash
reelforge validate part-journey
reelforge align part-journey          # after you save voice.wav in the episode folder
reelforge render part-journey
```

يوجد مثال مكتمل في `packs/manufacturing/examples/bracket-line-ar`؛ صدّره مع الخيار `--silent` للمقارنة.
