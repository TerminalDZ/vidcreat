# درس التعليم

في هذا الدرس تصنع فيديو موضوعه: شرح مفهوم واحد في 45 ثانية. ستستخدم الحزمة `education` وثيمها `campus`، ويستغرق العمل نحو عشر
دقائق قبل التسجيل.

## 1. أنشئ الحلقة

```bash
reelforge new concept-45s --pack education --template concept-explainer --lang ar
```

استخدم `--lang en` لنسخة إنجليزية. وتضم الحزمة أيضاً القالبين `study-plan` و`enrollment-steps`. يعرض [فهرس الحزم](../../reference/packs.md#education) كل القوالب
وحقولها.

## 2. أدخل بياناتك

افتح الحلقة بالأمر `reelforge edit concept-45s` واستبدل الأسماء والأرقام والكلمة المفتاحية الافتراضية
ببياناتك، أو ابدأ من لوحة التحكم (**+ New episode** ثم **Start from template**)، فيطلب النموذج كل حقل على حدة. التزم بحدود
الطول الظاهرة لكل حقل.

**الجمهور والنبرة.** الطلاب والأهالي والمعلمون. كن مشجعاً وواضحاً، بمفهوم واحد في كل حلقة.

- افتتح بسؤال سبق أن طرحه المشاهد على نفسه.
- ابنِ الفكرة خطوة بخطوة بمكوّن `steps` أو `tree`، عنصر لكل فكرة منطوقة.
- اختم بخلاصة قصيرة أو بسؤال للتعليقات.

## 3. راجع المحتوى

- التعريفات والمعادلات يجب أن تكون صحيحة؛ راجعها قبل التسجيل.
- لا امتحانات حقيقية ولا معلمين أو مدارس حقيقية.
- المحتوى الموجّه للقاصرين: لا طلب لبيانات شخصية ولا روابط لمحادثات خارج المنصة.

## 4. تحقق وسجّل وصدّر

```bash
reelforge validate concept-45s
reelforge align concept-45s          # after you save voice.wav in the episode folder
reelforge render concept-45s
```

يوجد مثال مكتمل في `packs/education/examples/photosynthesis-ar`؛ صدّره مع الخيار `--silent` للمقارنة.
