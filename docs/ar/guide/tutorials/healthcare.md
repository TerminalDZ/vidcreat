# درس الرعاية الصحية

في هذا الدرس تصنع فيديو موضوعه: دليل مدته 30 ثانية للزيارة الأولى في مستشفى خيالي. ستستخدم الحزمة `healthcare` وثيمها `clinical`، ويستغرق العمل نحو عشر
دقائق قبل التسجيل.

## 1. أنشئ الحلقة

```bash
reelforge new first-visit --pack healthcare --template patient-journey --lang ar
```

استخدم `--lang en` لنسخة إنجليزية. وتضم الحزمة أيضاً القالبين `department-intro` و`health-tip`. يعرض [فهرس الحزم](../../reference/packs.md#healthcare) كل القوالب
وحقولها.

## 2. أدخل بياناتك

افتح الحلقة بالأمر `reelforge edit first-visit` واستبدل الأسماء والأرقام والكلمة المفتاحية الافتراضية
ببياناتك، أو ابدأ من لوحة التحكم (**+ New episode** ثم **Start from template**)، فيطلب النموذج كل حقل على حدة. التزم بحدود
الطول الظاهرة لكل حقل.

**الجمهور والنبرة.** المرضى وعائلاتهم، وكثير منهم قلقون أو مستعجلون. استخدم نبرة هادئة ودافئة ولغة بسيطة، والعربية الفصحى مناسبة للمحتوى المؤسسي.

- اعرض اسم كل خطوة على الشاشة لحظة نطقها: الاستقبال، ثم الانتظار، ثم التمريض، ثم الطبيب.
- احتفظ باللون الأحمر للتحذيرات الحقيقية، واستخدم توهج `cyan` أو `lime`.
- اذكر رقماً واحداً على الأكثر (مثل مدة التسجيل المعتادة) وبيّن مصدره.

## 3. راجع المحتوى

- لا تشخيص ولا نصائح علاجية ولا جرعات ولا ادعاءات فعالية.
- لا مرضى ولا موظفين حقيقيين ولا حالات يمكن التعرف عليها؛ أسماء خيالية فقط.
- أضف عبارة «معلومات عامة وليست نصيحة طبية. استشر فريقك الطبي.» إلى نص المنشور إذا تناول الموضوع أعراضاً أو علاجاً.

## 4. تحقق وسجّل وصدّر

```bash
reelforge validate first-visit
reelforge align first-visit          # after you save voice.wav in the episode folder
reelforge render first-visit
```

يوجد مثال مكتمل في `packs/healthcare/examples/first-visit-ar`؛ صدّره مع الخيار `--silent` للمقارنة.
