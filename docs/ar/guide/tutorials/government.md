# درس الخدمات الحكومية

في هذا الدرس تصنع فيديو موضوعه: كيف يجدد سكان مدينة خيالية وثيقة عبر الإنترنت. ستستخدم الحزمة `government` وثيمها `civic`، ويستغرق العمل نحو عشر
دقائق قبل التسجيل.

## 1. أنشئ الحلقة

```bash
reelforge new renew-online --pack government --template renew-document --lang ar
```

استخدم `--lang en` لنسخة إنجليزية. وتضم الحزمة أيضاً القالبين `appointment-checklist` و`program-deadlines`. يعرض [فهرس الحزم](../../reference/packs.md#government) كل القوالب
وحقولها.

## 2. أدخل بياناتك

افتح الحلقة بالأمر `reelforge edit renew-online` واستبدل الأسماء والأرقام والكلمة المفتاحية الافتراضية
ببياناتك، أو ابدأ من لوحة التحكم (**+ New episode** ثم **Start from template**)، فيطلب النموذج كل حقل على حدة. التزم بحدود
الطول الظاهرة لكل حقل.

**الجمهور والنبرة.** جميع السكان، بمن فيهم كبار السن ومن لا يتحدثون اللغة بطلاقة. كن محايداً وبسيطاً وتدرّج خطوة بخطوة، والفصحى هي الأنسب.

- خطوة واحدة في كل سطر، تُعرض بمكوّن `steps` أو `checklist`.
- اعرض القناة الرسمية كنص، لا كشعار أو ختم حقيقي.
- أبقِ الترجمة النصية ظاهرة وتجنب المؤثرات السريعة.

## 3. راجع المحتوى

- حياد سياسي تام: لا أحزاب ولا مرشحين ولا آراء.
- القواعد والرسوم والمواعيد كما تُقدَّم حرفياً، مع عبارة «راجع الموقع الرسمي لحالتك».
- إمكانية الوصول: تباين عالٍ، ومن دون مؤثرات `flash` أو `glitch`.

## 4. تحقق وسجّل وصدّر

```bash
reelforge validate renew-online
reelforge align renew-online          # after you save voice.wav in the episode folder
reelforge render renew-online
```

يوجد مثال مكتمل في `packs/government/examples/westbrook-renewal-ar`؛ صدّره مع الخيار `--silent` للمقارنة.
