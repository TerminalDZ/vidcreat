# درس المالية

في هذا الدرس تصنع فيديو موضوعه: كيف تعمل ميزانية شهرية بسيطة. ستستخدم الحزمة `finance` وثيمها `ledger`، ويستغرق العمل نحو عشر
دقائق قبل التسجيل.

## 1. أنشئ الحلقة

```bash
reelforge new budget-basics --pack finance --template budget-basics --lang ar
```

استخدم `--lang en` لنسخة إنجليزية. وتضم الحزمة أيضاً القالبين `compound-interest` و`scam-alert`. يعرض [فهرس الحزم](../../reference/packs.md#finance) كل القوالب
وحقولها.

## 2. أدخل بياناتك

افتح الحلقة بالأمر `reelforge edit budget-basics` واستبدل الأسماء والأرقام والكلمة المفتاحية الافتراضية
ببياناتك، أو ابدأ من لوحة التحكم (**+ New episode** ثم **Start from template**)، فيطلب النموذج كل حقل على حدة. التزم بحدود
الطول الظاهرة لكل حقل.

**الجمهور والنبرة.** العملاء العاديون والشباب في بداية حياتهم المهنية وأصحاب المشاريع الصغيرة. كن محايداً وموثوقاً، واشرح المصطلحات المتخصصة مرة واحدة.

- استخدم `donut-chart` لتوزيع الميزانية و`counter` لمبلغ رئيسي واحد.
- ضع على الشاشة `label` مثل «قيم توضيحية» فوق الأرقام التوضيحية.
- فكرة واحدة في كل حلقة: الميزانية أو الفائدة أو الاحتيال، لا الثلاث معاً.

## 3. راجع المحتوى

- لا نصائح مالية: لا «اشترِ» ولا «بِع» ولا «استثمر في» ولا ترشيح لمنتجات أو توزيعات استثمارية محددة.
- لا وعود بعوائد ولا عبارة «بلا مخاطر».
- أضف «معلومات عامة وليست نصيحة مالية.» إلى نص المنشور، وعلى الشاشة عند ظهور الأرقام.

## 4. تحقق وسجّل وصدّر

```bash
reelforge validate budget-basics
reelforge align budget-basics          # after you save voice.wav in the episode folder
reelforge render budget-basics
```

يوجد مثال مكتمل في `packs/finance/examples/budget-split-ar`؛ صدّره مع الخيار `--silent` للمقارنة.
