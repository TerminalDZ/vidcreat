# البدء السريع: أول فيديو في 10 دقائق

ستصنع في هذا الدليل حلقة مدتها 30 ثانية من قالب قطاعي، وتعاينها دون تسجيل، ثم تضيف صوتك وتصدّرها. تحتاج
إلى [تثبيت](installation.md) ReelForge ونجاح الأمر `reelforge doctor`. تستخدم الأوامر هنا `reelforge`؛ اكتب
على Windows `reelforge.cmd`، وعلى macOS وLinux `./reelforge`.

## 1. أنشئ حلقة من قالب (دقيقة واحدة)

```bash
reelforge new clinic-intro --pack healthcare --template patient-journey --lang ar
```

ينشئ الأمر الملف `episodes/clinic-intro/episode.yaml` وفيه نص ومشاهد وcues تقديرية (draft)، فيمكنك معاينة
الحلقة فوراً. استخدم `--lang en` لتعليق صوتي بالإنجليزية. يعرض [فهرس الحزم](../reference/packs.md) كل الحزم
والقوالب، وتقدم لوحة التحكم الخيار نفسه عبر **+ New episode** ثم **Start from template**.

تفضّل البدء من الصفر؟ ينشئ الأمر `reelforge new ep10 --series "SYSTEM DESIGN"` قالباً مشروحاً بالتعليقات، أو
انقر **+ New episode** في لوحة التحكم (`start.bat` أو `./start.sh`).

## 2. افتح المحرر واجعل الحلقة لك (4 دقائق)

```bash
reelforge edit clinic-intro
```

- عدّل الأسطر في تبويب **Script** على اليسار. اجعل في كل سطر **جملة منطوقة واحدة**، بنحو 2.3 كلمة في
  الثانية. السطر الأول هو الافتتاحية (hook) التي تشد المشاهد.
- انقر على عنصر في مساحة العمل وغيّر نصه من لوحة الخصائص، أو انقر عليه مرتين لتعديله في مكانه. الكلمات بين
  `**` تأخذ لون التمييز: `**Duplicate** Charge`.
- لجعل عنصر يظهر عند كلمة، ضع مؤشر التشغيل على تلك الكلمة وانقر الزر **target** بجانب **Enter at**. يكتب
  المحرر زمناً مثل `l3:'desk'` يبقى مرتبطاً بالكلمة حتى بعد إعادة التسجيل.
- يضيف **Insert** مكوّناً (أو اسحب مكوّناً إلى مساحة العمل). واسحب المقاطع على الخط الزمني لإعادة
  توقيتها، فهي تلتصق بكلماتك.

يُحفظ كل تعديل في `episode.yaml` أولاً بأول، مع الحفاظ على التعليقات.

## 3. افحصها (دقيقة واحدة)

انتقل إلى **Review** (‏**Alt+3**). تأتي كل مشكلة، مثل نص يتجاوز صندوقه أو عنصر تحت أزرار المنصة، مع تلميح
لإصلاحها، وبالنقر عليها تنتقل إلى العنصر. ومن سطر الأوامر:

```bash
reelforge validate clinic-intro
reelforge snap clinic-intro l1+1 l3+1        # PNG frames in episodes/clinic-intro/out/snaps
```

## 4. سجّل وحاذِ (3 دقائق)

سجّل نفسك وأنت تقرأ النص بأي تطبيق (الهاتف أو Audacity أو OBS…)، واترك وقفة قصيرة بين الجمل. انقر **Upload
voice** في لوحة التحكم (تُحوَّل ملفات WAV وMP3 وM4A وOGG وOPUS وFLAC إلى `voice.wav`)، أو احفظ الملف باسم
`episodes/clinic-intro/voice.wav`. ثم حدد الـ cues:

```bash
reelforge align clinic-intro
```

افتح وضع **Cues** (‏**Alt+2**)، واستمع مرة واحدة إلى النهاية، وأصلح أي سطر بالسمع (اضغط **Space** عند بداية
السطر). يشرح دليل [التوقيت والـ cues والمحاذاة](timing.md) التفاصيل.

## 5. صدّر الفيديو (دقيقة للبدء)

```bash
reelforge render clinic-intro
```

أو انقر **Render** (‏**⌘/Ctrl+Enter**) في المحرر. عند الانتهاء، ارفع الملف
`episodes/clinic-intro/out/clinic-intro.share.mp4` مع نص المنشور والوسوم من `out/publish.md`. لم تسجّل بعد؟
يصدّر الأمر `reelforge render clinic-intro --silent` نسخة للمعاينة بالتوقيت التقديري.

> تفضّل العمل مع مساعد ذكاء اصطناعي؟ راجع [التكامل مع الذكاء الاصطناعي](ai.md). يستطيع المساعد أن يكتب النص
> ويبني المشاهد ويفحص الإطارات نيابةً عنك عبر خادم MCP.
