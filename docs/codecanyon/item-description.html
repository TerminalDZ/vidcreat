ReelForge — Voice + YAML → finished vertical explainer videos

Turn a voice recording and one simple text file into a polished vertical explainer video (1080×1920, 30 fps) for TikTok, Instagram Reels and YouTube Shorts — with animated diagrams, code that types itself, word-by-word captions, sound effects, mastered audio and platform-ready MP4 files. No video editor, no keyframes, no subscription, no AI.

You write what you say, sentence by sentence, and describe what appears on screen and on which word. ReelForge animates everything exactly when you say it. Re-record one sentence and everything after it stays in sync.

Perfect for

  • Developers and educators making technical explainer series (system design, programming, DevOps, data…)
  • Arabic creators who mix English terms — captions that are finally laid out correctly
  • Agencies producing consistent branded reels at scale
  • Trainers turning course material into short clips

Key features

  • Project dashboard — create episodes, upload your recording (WAV, MP3, M4A, OGG, FLAC…), mark cues, preview, validate and render with live progress, then play and download the results.
  • Cue marker — press Space at the start of each sentence while listening at 0.5×–1× speed; nudge by 10/50 ms, re-mark any line, word-level marks, snap-to-voice-onset, undo, autosave.
  • Live preview — the real 1080×1920 frame synced to your voice, reloading on every save, with TikTok/Reels/Shorts safe-zone overlays, element boxes and a lint panel.
  • 21 animated components — title, label, code, node, arrow (with moving packets), chip, stamp, table, lanes, checklist, counter, meter, timeline, grid, token bucket, phone mock-up, quote, particles, “The Trap” interstitial, call-to-action and icons.
  • Arabic-first captions — word-by-word karaoke highlight; right-to-left text with English terms in the correct order; “الـ client” kept together; punctuation on the correct side.
  • Professional audio — procedural sound effects on hits and transitions, voice mastered to −14 LUFS, effects ducked under the voice, true-peak limiter.
  • Platform-ready output — H.264 master, a share file that fits the size you choose, SRT captions, a contact sheet and a publish.md with your caption, hashtags and pinned comment. Every file is verified after encoding.
  • 13 validation rules — schema, timing, overlaps, off-screen elements, platform UI zones, text overflow and caption length, each with file:line:column and a fix hint.
  • Themes and presets — every color, font size and motion value in one YAML file; generate a full theme from one accent color.
  • Fast, parallel rendering — uses all your CPU cores; a 2-minute episode renders in about 5–10 minutes.
  • Offline and private — everything runs on your computer. No account, no upload, no per-video cost.
  • Deterministic — the same inputs always produce exactly the same frames.
  • Command line for automation and CI: studio, new, cue, dev, validate, render (batch), snap (cover image), doctor, theme, schema — with JSON output.

What you get

  • Full TypeScript source code (monorepo, strict mode, 98 automated tests)
  • One-click installers for Windows, macOS and Linux
  • Nine complete example episodes (Season 1 of “System Design بالعربي”)
  • Three themes and three platform presets (TikTok, Reels, Shorts)
  • Offline HTML documentation with screenshots, a component reference and troubleshooting

Requirements

  • Windows 10/11, macOS 13+ or Linux
  • Node.js 22 LTS (free) and FFmpeg 6+ (free) — the installer sets them up for you where possible
  • 4 CPU cores and 8 GB RAM minimum

Notes

  • ReelForge does not generate voices or visuals with AI: you record your own voice and design scenes in a simple YAML file (autocompletion included for VS Code).
  • The bundled fonts (Cairo, Space Grotesk, JetBrains Mono) are under the SIL Open Font License; credits are included.
  • The videos you create are yours to use commercially.
