CLI reference ​

Every reelforge command and option, generated from the command definition in packages/cli/src/index.ts. On Windows run reelforge.cmd, on macOS and Linux ./reelforge, or pnpm reelforge from a source checkout. Exit codes: 0 success, 1 failure (or validation errors), 2 usage error. The command line guide explains environment variables and common workflows.

Global options ​

These options go before or after any command.

OptionDescriptionDefaultRequired
-V, --versionoutput the version number
--verbosemore output (info messages, logs)
--jsonmachine-readable JSON output
--root <dir>project root (default: $REELFORGE_ROOT or the current directory)

reelforge studio ​

open the project dashboard: create episodes, upload voice, open the editor, validate and render

text
reelforge studio [options]
OptionDescriptionDefaultRequired
--port <port>port (default 4310 or $REELFORGE_PORT)
--host <address>bind address (default 127.0.0.1 or $REELFORGE_HOST); other addresses require the bearer token
--no-opendo not open the browser

reelforge new ​

create episodes/<id>/episode.yaml from a commented template

text
reelforge new [options] <id>
ArgumentDescriptionRequired
idepisode id (slug)yes
OptionDescriptionDefaultRequired
--series <name>series name shown in the header
--episode <n>episode number
--lang <en|ar>language of the template script (default en)
--pack <id>start from an industry pack template (see reelforge packs)
--template <id>template of the pack (default: the pack's first template)
--slot <key=value>template slot value (repeatable); missing slots keep their defaults

reelforge align ​

mark cues automatically from the voice recording (lines and words; writes cues.json)

text
reelforge align [options] [id]
ArgumentDescriptionRequired
idepisode id or path
OptionDescriptionDefaultRequired
--engine <name>auto: whisper when installed, else dsp (one of auto, dsp, whisper)
--model <size>whisper model size (default base) (one of tiny, base, small)
--no-vaddetect speech by energy only (skip Silero VAD)
--no-wordsonly line cues
--forcereplace cues you marked by hand
--dry-runprint the result without writing cues.json
--setupinstall the optional speech models (one time, ~180 MB in the user cache)
--statusshow which speech models are installed

reelforge render ​

render master + share MP4, SRT, contact sheet and publish.md

text
reelforge render [options] [id]
ArgumentDescriptionRequired
idepisode id or path (or a folder of episodes with --all)
OptionDescriptionDefaultRequired
--allrender every episode in episodes/ (or in the given folder)
--preset <name>tiktok | reels | shorts (default: meta.preset, $REELFORGE_PRESET)
--workers <n>parallel Chromium workers (default: CPU cores − 1, $REELFORGE_WORKERS)
--from <t>partial render start (seconds) → <id>.part.mp4
--to <t>partial render end (seconds)
--share-size <MB>share file size cap (default 28, $REELFORGE_SHARE_SIZE)
--no-sfxrender without sound effects
--no-shareskip the share file
--losslesscapture PNG frames instead of JPEG
--fastfaster master/share encoding (preset medium)
--silentallow rendering without a voice recording
--keep-tmpkeep out/.tmp/<run-id>/ on failure
--no-measureskip the headless V-9/V-10 checks
--denoiseremove background noise from the voice (default: audio.denoise)
--no-denoisekeep the voice as recorded, even when audio.denoise is true
