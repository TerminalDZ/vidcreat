مرجع سطر الأوامر (CLI) ​

كل أوامر reelforge وخياراته، مولّدة من تعريف الأوامر في packages/cli/src/index.ts. على Windows شغّل reelforge.cmd، وعلى macOS وLinux شغّل ./reelforge، أو pnpm reelforge من نسخة المصدر. رموز الخروج: 0 نجاح، و1 فشل (أو أخطاء تحقق)، و2 خطأ في طريقة الاستخدام. يشرح دليل سطر الأوامر متغيرات البيئة وطرق العمل الشائعة.

ملاحظة: هذه الصفحة مولّدة من الكود. العناوين والشرح بالعربية، أما الأوصاف داخل الجداول فتُقرأ من الكود وتبقى بالإنجليزية.

text

reelforge align ​

mark cues automatically from the voice recording (lines and words; writes cues.json)

text
reelforge align [options] [id]
الوسيطالوصفإلزامي
idepisode id or path
الخيارالوصفالافتراضيإلزامي
--engine <name>auto: whisper when installed, else dsp (إحدى القيم auto, dsp, whisper)
--model <size>whisper model size (default base) (إحدى القيم tiny, base, small)
--no-vaddetect speech by energy only (skip Silero VAD)
--no-wordsonly line cues
--forcereplace cues you marked by hand
--dry-runprint the result without writing cues.json
--setupinstall the optional speech models (one time, ~180 MB in the user cache)
--statusshow which speech models are installed

reelforge render ​

render master + share MP4, SRT, contact sheet and publish.md

text
reelforge render [options] [id]
الوسيطالوصفإلزامي
idepisode id or path (or a folder of episodes with --all)
الخيارالوصفالافتراضيإلزامي
--allrender every episode in episodes/ (or in the given folder)
--preset <name>tiktok | reels | shorts (default: meta.preset, $REELFORGE_PRESET)
--workers <n>parallel Chromium workers (default: CPU cores − 1, $REELFORGE_WORKERS)
--from <t>partial render start (seconds) → <id>.part.mp4
--to <t>partial render end (seconds)
--share-size <MB>share file size cap (default 28, $REELFORGE_SHARE_SIZE)
--no-sfxrender without sound effects
--no-shareskip the share file
--losslesscapture PNG frames instead of JPEG
--fastfaster master/share encoding (preset medium)
--silentallow rendering without a voice recording
--keep-tmpkeep out/.tmp/<run-id>/ on failure
--no-measureskip the headless V-9/V-10 checks
--denoiseremove background noise from the voice (default: audio.denoise)
--no-denoisekeep the voice as recorded, even when audio.denoise is true

--every <seconds>one frame every N seconds
--out <dir>output folder (default out/snaps)
--preset <name>override meta.preset
