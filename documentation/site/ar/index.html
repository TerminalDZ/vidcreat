المظهر

ReelForgeصوتك وملف YAML واحد يصنعان فيديو عمودياً جاهزاً للنشر

فيديوهات شرح بمقاس 1080×1920 لـ TikTok وReels وShorts. مكوّنات متحركة تظهر عند نطق كلماتك، وترجمة نصية بالعربية والإنجليزية، وصوت معالَج باحتراف. يعمل محلياً ودون اتصال بالإنترنت، وبنتائج ثابتة.

البدء السريع
مقدمة
GitHub

متزامن مع كلماتك

يظهر كل عنصر عند نطق الكلمة التي تسميه. أعد تسجيل سطر فتتبعه كل الحركات، لأن الأزمنة تُكتب بالكلمات لا بالثواني.

محرر حقيقي

مساحة عمل بأدلة محاذاة ذكية، وطبقات، ولوحة خصائص تعرض كل خاصية، وخط زمني يلتصق بكلماتك. ويُحفظ كل تعديل في episode.yaml.

قوالب لقطاعات كثيرة

حزم قطاعية للرعاية الصحية والعقارات والخدمات اللوجستية والتعليم والمالية وغيرها. املأ بضعة حقول فتحصل على حلقة مصمَّمة.

العربية والإنجليزية

ترجمة نصية تظهر كلمة بكلمة في الاتجاهين، وتحافظ الجمل العربية على الترتيب الصحيح للمصطلحات الإنجليزية داخلها.

يعمل مع مساعدي الذكاء الاصطناعي

خادم MCP (عبر stdio وHTTP) وواجهة REST مع OpenAPI يتيحان الأدوات نفسها لأي عميل. واستخدامهما اختياري.

لا ذكاء اصطناعي في محرك الرسم

دالة رسم نقية ترسم كل إطار، ثم يرمّزه FFmpeg. والمدخلات نفسها تنتج الفيديو نفسه دائماً.
